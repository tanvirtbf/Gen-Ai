------------------------------------------------------------
LINE 28-31: Text Splitter Setup
------------------------------------------------------------

const textsplitter = new RecursiveCharacterTextSplitter({
  chunkSize: 500,
  chunkOverlap: 100,
});

→ Text ke choto choto chunk e vag korar tool toiri kora hocche.

→ chunkSize: 500 — protita chunk e maximum 500 characters thakbe.
  Keno 500? Karon:
  - Onek boro text ekbar e LLM e pathale relevant part khuije pay na
  - Choto chunk hole specific answer dite pare
  - Embedding o choto text e better kaj kore

→ chunkOverlap: 100 — 2 ta consecutive chunk er moddhe 100 characters common thakbe.
  Keno overlap? Karon:
  - Jodi ekta important sentence 2 ta chunk er boundary te pore, tahole overlap
    thakle sei sentence ta haray na
  - Example:
    Chunk 1: "...company founded in 2020. Our mission is to"
    Chunk 2: "Our mission is to provide the best AI solutions..."
    → "Our mission is to" part ta duita chunk ei ache — tai info loss hoy na

→ "Recursive" mane: prothome paragraph boundary (\n\n) te split try kore,
  na parle sentence (\n) e, tarpor space e, sheshe character e — intelligently
  split kore.

LINE 33: Text Split Execute Kora

→ doc[0].pageContent — purota PDF er text content (ekta long string).

→ texts hocche ekta string array.
  Jemon: ["chunk1 text...", "chunk2 text...", "chunk3 text...", ...]
→ Apnar case e 35 ta chunk toiri hoyechilo.


------------------------------------------------------------
LINE 35-40: Chunks ke LangChain Document Format e Convert Kora
------------------------------------------------------------

const documents = texts.map((chunk) => {
  return new Document({
    pageContent: chunk,
    metadata: doc[0].metadata,
  });
});

→ Protita text chunk ke LangChain er Document object e convert kora hocche.
→ Protita Document e 2 ta jinis thake:
  - pageContent: chunk er actual text
  - metadata: original PDF er metadata (source file name, page count etc.)
→ Keno Document class use kora hoy:
  - LangChain er sob tool (vector store, retriever) Document format e kaj kore
  - metadata thakle poore retrieve korar somoy bujha jay chunk ta kon file theke
    eshechilo

→ IMPORTANT: metadata lowercase 'm' hote hobe. Uppercase 'M' (Metadata) likhle
  LangChain chine na — error dey. (Ei bug ta age chilo apnar code e, fix kora
  hoyeche.)


------------------------------------------------------------
LINE 43: Vector Database e Store Kora
------------------------------------------------------------

await vectorStore.addDocuments(documents);

→ ETA hocche main line — behind the scene 2 ta kaj hoy:

  Step 1 — Embedding Generate:
  Protita document er pageContent ke OpenAI er embedding model e pathay.
  "ami valo achi" → [0.23, -0.45, 0.12, ...] (1536 ta number er array)
  Ei number gulo text er meaning represent kore.

  Step 2 — Pinecone e Store:
  Generated vectors + metadata + text Pinecone database e upsert (insert/update)
  kore.

→ maxConcurrency: 5 er jonno, 5 ta document er embedding ek sathe generate hoy —
  tai fast hoy.
→ Internally 100 ta kore batch e Pinecone e pathay (chunkSize = 100 inside
  LangChain).
